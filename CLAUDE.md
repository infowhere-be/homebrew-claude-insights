# homebrew-claude-insights

Tap Homebrew oficial do InfoWhere para o `claude-insights` — dashboard em tempo real para sessões do Claude Code. Este repo contém apenas a fórmula de instalação.

## Convenções

- A fórmula (`Formula/*.rb`) segue as convenções do Homebrew; versão e SHA256 atualizados a cada release do claude-insights.
- Não editar a fórmula à mão em release: o processo de release do projeto principal é quem a atualiza.
